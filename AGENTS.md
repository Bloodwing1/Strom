# Strom: smart heating

Strom is a CLI tool and Desktop app to smartly control electrical heaters connected to a smart plug.

The priorities of the codebase are maintanability and following YAGNI principles. The code is the truth, dont document anything that is obvious from the code.

## Commit attribution
End every commit message with a trailer naming the model that performed the
work:

    Co-authored-by: DeepSeek V4.1 Flash

Name the model that actually did the work, not the one that started the
session. When several models contribute, add one trailer per model.
