# Strom app icon

The selected Little Radiator icon uses cream enamel, chrome, and a warm
amber glow, inspired by classic Mac desktop application icons.

`strom-radiator-original.png` is the unchanged 1254 × 1254 generated master,
with transparency. Keep this file for future exports. The `strom-SIZE.png`
files are smooth downscaled desktop versions; Qt selects a suitable size.

Generated using the built-in image generation tool. The original prompt is
recorded in `design/icon-candidates/prompts.md` at the repository root.
